# DATA PET — BIT Sui-Inspired Mascot Asset Pack

This pack contains one cohesive set of eight PNG mascot poses for the DATA PET browser game. The mascot is an original Sui-inspired blue water-drop companion named BIT. It is a community-created concept, not an official Sui mascot and not an official Sui or DATA Foundation asset.

## Files

- `assets/bit/bit-idle.png` — welcome / idle
- `assets/bit/bit-wave.png` — greeting / adoption screen
- `assets/bit/bit-inspect.png` — inspecting a data capsule
- `assets/bit/bit-happy.png` — successful decision / thumbs-up
- `assets/bit/bit-thinking.png` — unclear permissions / hold for review
- `assets/bit/bit-glitch.png` — playful incorrect decision reaction
- `assets/bit/bit-evolved.png` — high-trust / evolved state
- `assets/bit/bit-celebrate.png` — final results celebration
- `assets/bit/bit-character-sheet.png` — transparent character reference sheet
- `BIT-assets-preview.jpg` — preview on a dark background

The individual PNGs are transparent. For Codex, copy the individual PNG files to the project at `public/assets/bit/` (and optionally copy the character sheet to `public/assets/bit/bit-character-sheet.png`). Keep the character proportions intact and render each image with `object-fit: contain`.

## Visual identity

BIT is a cute, expressive blue water-drop creature with a crystal tip, big reflective eyes, cyan highlights, and a white flowing belly mark. The look is inspired by Sui's blue visual language, while the character itself is an original community concept. Avoid presenting it as an official brand mascot.
